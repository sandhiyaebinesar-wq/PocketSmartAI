# PocketSmart AI – Smart Budget & Recommendation Assistant

PocketSmart AI is an AI-powered budget and recommendation assistant that helps users plan their requirements based on their budget, preferences, and occasion.

## Features

- 🔐 User Registration and Login
- 🏠 Home Planner
- 🎉 Party Planner
- 💎 Jewelry Planner
- 🤖 AI-powered recommendations using Gemini
- 💰 Budget-based recommendations
- 🛍️ Product search links
- 📜 Recommendation history
- 📱 Responsive web interface
- 🔄 Fallback recommendations when AI is unavailable

## Technology Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI
- SQLite

### AI
- Google Gemini API
